Investment Portfolio Tracker

Datheon Python Programming Internship – Task 1

Project Description

A Python-based investment portfolio tracking utility that allows users to enter stock ticker symbols, purchase prices, share quantities, and current market prices.

The application calculates investment value, profit or loss, and percentage performance for each stock.

Features

- Collect stock investment information.
- Calculate total invested capital.
- Calculate current portfolio value.
- Calculate individual stock profit and loss.
- Calculate percentage gain or loss.
- Export portfolio summaries into a CSV file.

Technologies Used

- Python 3
- CSV module
- Dictionaries
- Loops
- File handling

Project Files

- "portfolio.py" – Main application.
- "portfolio_summary.csv" – Generated investment report.

How to Run

1. Install Python 3.
2. Open the project folder in your terminal.
3. Run:

python portfolio.py
