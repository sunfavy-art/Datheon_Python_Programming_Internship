Task 2: File Organizer

Project Description

This Python project automatically organizes files into different folders based on their file extensions.

Features

- Checks whether the selected folder exists.
- Identifies file extensions.
- Creates category folders automatically.
- Moves files into appropriate folders.
- Handles duplicate filenames.
- Handles permission and operating system errors.
- Displays an organization summary.

File Categories

- Documents: PDF, DOCX, TXT
- Images: JPG, JPEG, PNG, GIF
- Videos: MP4, MKV
- Audio: MP3, WAV
- Archives: ZIP, RAR
- Code: PY, HTML, CSS, JS

Requirements

- Python 3
- Standard Python libraries: os, shutil, pathlib

How to Run

1. Open the project folder in VS Code.
2. Run Organizer.py.
3. Enter the folder path when prompted.
4. The program will organize the files automatically.
