Overview

This repository contains two Python programming projects developed as part of the Datheon Python Programming Internship.

The projects demonstrate practical skills in Python programming, data processing, file handling, automation, and error handling.

Completed Projects

Task 1: Investment Portfolio Tracker

A Python application that helps users track stock investments and calculate portfolio performance.

Features:

- Record stock symbols, purchase prices, and quantities.
- Calculate total investment value.
- Calculate profits and losses.
- Calculate percentage gains or losses.
- Export portfolio summaries to CSV.

Main File: "Task_1_Portfolio_Tracker/portfolio.py"

Task 2: Automated File Organizer

A Python automation tool that organizes files into folders based on their extensions.

Features:

- Identify file extensions.
- Automatically create category folders.
- Organize documents, images, videos, audio, archives, and code.
- Handle duplicate filenames.
- Handle permission and file-system errors.
- Display a summary of organized files.

Main File: "Task_2_File_Organizer/Organizer.py"

- Exception handling
